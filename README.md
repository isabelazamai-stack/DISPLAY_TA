# Estudo da Propriedade Display no CSS

---

## 📋 Descrição do Projeto

Este projeto foi desenvolvido com o objetivo de **estudar, testar e consolidar o conhecimento sobre a propriedade `display` do CSS**. 

A propriedade `display` é uma das mais importantes para o controle de layout e fluxo de elementos em uma página web. Neste repositório, explorei os principais valores e comportamentos dessa propriedade, criando exemplos práticos para cada um deles:

*   **`display: none`**: Oculta completamente o elemento da página, removendo-o do fluxo visual.
*   **`display: block`**: Faz com que o elemento ocupe toda a largura disponível, quebrando a linha antes e depois dele.
*   **`display: inline`**: Mantém o elemento na mesma linha do texto ao redor, respeitando apenas o conteúdo interno (sem aceitar larguras e alturas personalizadas).
*   **`display: inline-block`**: Combina o melhor dos dois mundos: permite que os elementos fiquem lado a lado (como o `inline`), mas aceita propriedades de largura, altura, margens e preenchimentos (como o `block`).
*   **`display: flex` (Flexbox)**: Um modelo de layout unidimensional poderoso para alinhar, distribuir espaço e organizar itens de forma dinâmica e responsiva.
